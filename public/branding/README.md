# VORTEX 3.0 branding assets

All SVG logo assets in this folder have transparent backgrounds. Use `vortex-mark.svg` for icons/favicons and `vortex-wordmark.svg` for the primary horizontal wordmark. `vortex-wordmark-dark.svg` is intended for light backgrounds.

The SVGs are vector source assets and can be exported to transparent PNG at any required resolution. The old `/logo-v.png` asset remains in `public/` for compatibility with legacy references.
